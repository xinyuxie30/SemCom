# 32 状态决策组件小试（正式实验前）

2026-09-26，在查看保留图像的动作标签和模型输出前固定。

P1 的冻结裁剪编解码器没有通过单轮基线门槛。因此本阶段仅核查模型决策与部署可行性，不将它称为已经通过 P2 或支持完整方法优越性的实验。

- 图像：Kodak 17–24，共 8 张保留开发图。未用于 P1 的融合规则选择。
- 状态：仅 C128 首轮，SNR 0/6、年轻/老化 CSI、首个信道片段，共 32 状态。
- 动作：四象限、全局补充、停止；主融合固定 alpha=0.5。
- 固定对照：P1 最优固定区域 upper_right；global；stop；四区域均匀随机的期望表现；视觉前端严重程度排序。
- 视觉比较：原始 Qwen3-VL-4B 与发布的 Visual Jev 4B 适配器，使用相同图像、状态、候选读出及问题；不微调。
- 视觉输入统一从接收端浮点结果转为 8-bit RGB，再 bicubic 放大到 448×448；放大不增加原图信息。两条视觉臂使用相同转换。
- 官方 Jev：只接收公开开发图像的接收端描述与已知协议状态。视觉描述由固定 Qwen 前端产生，记录其成本；不会上传原图或未公开文稿。
- 前端描述预定为四区域的可见损伤等级，不将原图、真实误差、最优动作或未来 CSI 传入任一模型。
- Jev 的同描述规则对照根据严重程度排序；视觉模型之间才做同像素条件的准确率比较。
- 同描述增加原始 Qwen 的固定灰图控制：保留同一结构化描述但不提供样本图像，用于同信息量比较。灰图是常量输入，不代表另一个视觉样本。
- 每个状态的六个动作按固定哈希随机排列；全部模型共享该排列。区域描述选项固定为 low / noticeable / severe / uncertain。
- 严格命中率：选择 hindsight oracle 的动作；并报告选中动作 MSE 不超过 oracle 1.02 倍的近优命中率，避免等价选择被过度惩罚。
- 主要实用指标：相对 oracle 的平均 PSNR 损失，以及相对固定对照的 MSE/PSNR 差异。
- 所有网络错误和超时保留，预设回退 upper_right。现场请求不用于调 prompt；不因不佳结果追加候选模板。
- 这 8 张图只提供组件小试，不足以证明统计优势。以后不能再称其为未观察的正式测试集。
- 时序：组件评估使用固定动作表，明确不计模型等待；另报告真实模型时延，不宣称在线闭环收益。
- 运行环境可能与论文的 torch 2.14 / CUDA 13 不同，记录差异，定位为代码可移植性验证。
