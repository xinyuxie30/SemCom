# 完整实验协议 v1

## Material Passport

- 工作流：academic-research-suite / experiment-agent / plan + engineering validation。
- 更新时间：2026-09-28；状态：正式配置已准备，小规模端到端与恢复检查通过，**正式实验尚未执行**。
- 问题：固定 DCAT 编解码器下，Jev 的接收端描述特征能否改善增强收益预测、区域选择及停止决策？
- 本协议取代早期报告中的未来执行计划；旧预实验及失败门槛原样保留，不改写为成功。
- 证据等级：公开权重推理 + 开发小试。不是 DCAT 全训练复现、不是 SOTA 结论，也不是已证明的论文创新。

## 1. 已知结果与本次准备的范围

P1 的 C128+C64 oracle 比开发集最佳固定动作约高 0.314 dB，但比相同载荷的单轮 C192 低 0.896 dB。旧协议的“oracle 至少匹配单轮”门槛**未通过**。因此不能据此建议立即投入新的渐进编解码器大规模训练。

后续 8 张开发图、32 个状态的原始决策评测中，官方 Jev 最优动作命中率 34.4%，Visual Jev 为 28.1%。官方成功返回的 31 次全部选择全局增强；另一次网络错误按预定规则回退。Visual Jev 选择全局增强 26 次、停止 6 次。原始决策器尚无有效区域选择证据。

用户要求将工程推进到可直接运行完整实验。本目录因此准备了一个**冻结 codec 的决策验证实验**：允许检验收益校准是否有效，也允许得到否定结果。它没有将 P1 的科学门槛改为通过。正式运行与是否值得投入更多训练，是两个决策。

## 2. 数据与实验矩阵

| 用途 | 图像数 | 分组 |
|---|---:|---|
| UDIS 选择器训练 | 512 | 256 个关联图像组件，各取 2 张唯一图像 |
| UDIS 验证、选择训练轮数 | 128 | 64 个独立组件 |
| UDIS 测试 | 512 | 256 个独立组件 |
| DIV2K 外部测试 | 100 | 官方 validation HR 0801–0900，全部用作本研究外部测试 |

UDIS 同编号双视图先合并，再按共享的精确图像哈希传递合并。不同编号复用图像的情况不能仅靠文件名划分解决。每组件固定选择两张不同图像；组件之间按哈希确定训练/验证/测试归属。剩余 UDIS 图像不使用。组件只是已知图像关联的代理，不能保证所有视觉相似但像素不相同的场景都已识别。

UDIS 先前已用于公开权重的整体推理结果；这不是完全未见过的基准。新 DIV2K 的模型结果在正式启动前不生成、不用于选择方法。开发用 Kodak 全部排除于正式结果。所有图像统一 RGB、128×128；不是原始高分辨率数据集排行榜协议。

UDIS：A9 × SNR {0,6} × 首轮最后符号 CSI 年龄 {young,old} × 3 个采样重复。
DIV2K：相同条件，额外加入 A1。总计 **16,224 状态**，其中测试/外部测试为 **8,544 状态**。每状态一次官方请求，多个 Choice/Noul 问题放在同一请求内；三次小网络训练共用原始模型输出。

年龄区间分别为 [0.25,0.75] ms 和 [3,3.5] ms。三个重复的首轮起点来自同一公开轨迹的三个不相交早期窗口，并有独立加性噪声；后续长延迟轨迹可以重叠。不能将其称为三条独立传播轨迹。

## 3. 冻结的传输机制

- 首轮 C128 全图；增强轮 C64，4 个象限、全局增强和停止，共 6 个动作。
- 局部 64×64 原图双线性放大到 128×128，独立编码；解码后缩小，选中区域按 α=0.5 与首轮等权融合。
- 单轮 C192 为相同载荷对照。所有 DCAT 权重冻结。
- 真实原图、未来真实信道及真实 MSE 只生成监督/诊断结果，保存在 `labels/`。模型推理阶段只读取 `states/` 与接收图数组。
- 相同状态不同动作使用绝对时间索引一致的噪声；相同时间重复推理可恢复同一噪声。不会为某个方法挑选更有利噪声。

这是本地实现的简化独立 ROI 编码，不是原生可训练渐进 codec，也不是 ROI 反馈论文的完整复现。单轮码率只有 C64/128/192 等离散权重，不能声称单轮对照精确消耗了每一个剩余控制符号。

## 4. Jev 与对照

官方固定 `jev-1.13.0`，通过 TypeSafe 直连；Visual Jev 使用作者固定提交的 Qwen3-VL-4B + answer-SFT LoRA。本地量化方式为 bf16，公开权重冻结。软件版本与作者环境不同，属于本地移植推理。

正式提示词 v1 与开发提示词的预先声明区别：**所有基础模型均只见接收图/接收端描述和固定协议，不见 SNR、CSI 幅度或 CSI 年龄**。链路数字由后续数值模型处理。这样，去掉年龄的消融不再通过 Jev 输出间接读回同一数字。该修改尚未在正式测试结果上调参。

对照包括：单轮 C192、停止、全局增强、固定右上角、随机区域、图像梯度重要性、描述严重程度规则、原始官方 Jev、原始 Visual Jev、同底座 Qwen 图像读出、同描述 Qwen 读出。

收益学习器：相同 61 维输入槽位、两层 64 单元 MLP；不使用的槽位置零。分别使用数值特征、数值+描述、数值+官方 Jev、数值+Visual Jev、数值+Qwen。还包括数值/官方/Visual 的年龄消融，以及官方/Visual 禁止停止的消融。仅不确定性对照预测各区域当前重建 MSE，再选预测误差最高的区域。

三训练种子固定为 11/29/47。训练最多 300 轮，Adam lr=0.001，验证损失连续 25 轮不改善则停止。归一化只用训练数据；轮数只用验证数据。测试标签在完成选择之前不读取。

目标为相对 MSE 降幅 `(MSE_base-MSE_action)/MSE_base`，训练时截断到 [-4,1]，报告误差对未截断目标计算。停止的预测增益固定为零。所有基础模型特征都是不确定的输入，官方概率不直接当作真实质量概率。

## 5. 资源与延迟：分成两个报告

### A. 固定执行时刻的决策诊断

所有方法用首轮后固定 0.125 ms 间隔的动作结果表。评价最优动作命中率、2% MSE 容差命中率、PSNR 选择损失和最终质量；单独报告真实决策耗时。这个表**不表示 API 在 0.125 ms 内返回**，也不用于端到端低延迟优势结论。

### B. 实测决策等待的信道回放

每种方法独立使用自身一次实测决策耗时，包含必要的图像准备、描述前端、API 与小网络。其他实验分支的计算耗时不算到该方法上。三训练种子共用基础模型输出，训练时间不算在线推理时间。

收到决策后等待下一个周期导频，支付导频、反馈和头部费用，然后按新的绝对信道时间重新编码/重建所选增强。等待 API 期间不免费读取中间导频；仅等待结束后新观测的导频可用。基线 C192 立即单轮发送。

回放将首轮完整 codec 调用耗时保守计为接收后的计算等待，并加上增强 codec 实测调用耗时。这是声明了假设的时序仿真，不是硬件无线链路的实测端到端时延；编码/解码没有进一步拆分。截止时间 2,500 ms，超过时保留首轮重建，并记录已经消耗的资源。

共同总预算上限 **6,656 复符号**。载荷首轮 4,096、增强 2,048；每个头部 32、区域/序号反馈 64、每次实际观测导频 64。首轮和增强各按覆盖区间的导频更新数收费。分别记录载荷、前向头部/导频、反向反馈与闲置预算。是同上限比较，不是所有方法精确等耗费。

反馈使用预设独立 1% 包擦除模型，所有方法共享同状态的擦除抽样，失败保留首轮图。这个比例是仿真假设，不是 TypeSafe 错误率或实测无线控制错误率。头部采用可靠控制信令假设，未实现具体 FEC/调制。RF 能量以每复符号单位发射能量计算；CPU/GPU 和 API 服务能量未测量，不声称总系统能耗下降。

## 6. 评价与判断

分别报告 UDIS、DIV2K-A9、DIV2K-A1，不拼成跨数据集总成绩。报告平均 PSNR/MSE/LPIPS(normalize=True)、PSNR 第 5 百分位数、预先固定的 20 dB 失真率、通信各项、延迟、截止失败率及预测增益误差。20 dB 门槛在开发小试看过之后固定，正式数据不再调整。

主比较：**官方 Jev 收益学习器 vs 同样描述前端的收益学习器**。次比较：Visual Jev vs Qwen；移除年龄；禁止停止；单轮 C192。训练种子先在同一状态内取平均，再按图像关联组件/外部图像进行 2,000 次配对 bootstrap。不同信道/SNR/年龄重复不算独立图像。区间是描述性、未做多重比较调整，不能挑一个显著子组作为总体有效的证明。样本规模是固定计算预算设计，没有声称已达到稀有事件检验功效。

Jev 独立价值需要主比较稳定改善；CSI 年龄与停止各自需要对应消融；无线系统收益需要延迟回放与单轮对照同时支持。若只提高固定时刻选择准确率而回放失去优势，结论限于离线/延迟宽松决策。若没有收益，应报告否定结果或回到 codec 设计，不能把接入新模型本身写成有效创新。

## 7. 可复现与启动边界

运行前检查数据、模型、作者代码、本地脚本哈希，保存配置和源码快照。每个状态原子写入独立 JSON，断点恢复只跳过已完整保存的状态；代码/权重变化会拒绝混用旧运行。API 无自动重试，异常保留并回退为停止；认证错误或连续 5 次失败停止整阶段，保留中间结果。

请求先落盘 attempt 再发送；若进程在发送后保存前中断，不重发该状态，而记录结果未知及保守的超时等待上界。Choice 允许 API 在并列最高概率中选择任一项；两位小数概率仅在舍入误差范围内归一化，原始响应保留。错误结构、非有限值、越界概率、非最大值选择和模型版本变化仍拒绝。依据 [官方 API 文档](https://docs.typesafe.ai/api)，Choice 与 Noul 字段分别验证。token 汇总仅覆盖实际返回的 usage，网络失败的远端计费无法从客户端确定。

正式运行最多 16,224 次官方请求。按开发请求约 1,290 输入 token/状态估算约 2,100 万输入 token，实际由返回 usage 汇总；不保证此估计或服务价格。按现有小试粗估整轮为十几到二十几小时，受接口、GPU和回放分支影响。预检和 smoke 都不能替代正式结果。
